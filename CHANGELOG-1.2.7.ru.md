# ИванОператор 1.2.7

Основа — 1.2.6 / 1.2.5 (все исправления сохранены: отправка снимков, тот же чат, «Максимум повторов на задачу», быстрые адаптивные паузы).

## Настоящий установщик Windows
- IvanOperator-Setup-1.2.7.exe собирается на Linux БЕЗ wine: electron-builder (папка win-unpacked) → resedit (MIT) записывает иконку и сведения о версии в IvanOperator.exe → нативный makensis (NSIS, zlib) собирает установщик (scripts/build-win.js, scripts/win-setup.nsi).
- Установка для текущего пользователя в %LOCALAPPDATA%\Programs\IvanOperator, ярлыки на рабочем столе и в «Пуске», удаление через «Приложения и возможности». Выбор папки, русский интерфейс.
- install.cmd сначала запускает Setup.exe; если его нет — ставит переносную версию.

## Параллельное решение для управления экраном
- Новое действие screen_vote: несколько вариантов следующего действия (разные ИИ при включённом «Автовыбор модели», иначе только выбранный ИИ несколько раз), голосование по кластерам (близкие координаты, одинаковый текст), выполнение лучшего с проверкой изменения экрана, при неудаче — второй вариант. Опасные действия (run и т.п.) в голосование не допускаются; обычные подтверждения сохраняются.

## Подстройка под изменения интерфейса чатов
- Поле ввода ищется по смыслу: placeholder/aria-label/role на любом языке («Напишите сообщение», «Ask anything»…), затем по старому списку селекторов, затем «зрением» (точки внизу окна).
- Найденное поле превращается в устойчивый селектор (#id, data-testid, aria-label, placeholder) и запоминается; при смене интерфейса — сообщение в журнале и самовосстановление.

## Визуальный анализатор
- Новые эвристики: модальное окно (затемнённые края), загрузка (меняется только маленький участок).
- analyze_screen с ai:true (или настройкой visualAI) дополнительно отправляет снимок выбранному ИИ и возвращает вердикт, проблемы и следующий шаг. Если отправка картинок выключена — ИИ-анализ не выполняется.

## Библиотеки
resedit + pe-library (MIT, только для сборки), NSIS/makensis (zlib/libpng), Pillow (HPND, только для сборки icon.ico), плюс всё из 1.2.6.
