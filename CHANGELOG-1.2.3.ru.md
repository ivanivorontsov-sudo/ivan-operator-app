# ИванОператор 1.2.3

## Снимки экрана в веб-чатах (ГигаЧат, DeepSeek, Алиса)
- Порядок прикрепления: сначала вставка из буфера обмена (clipboard.writeImage + настоящий Ctrl+V), затем кнопка «скрепка»/«+» с перехватом выбора файла, и только в конце прямая подстановка в input[type=file].
- ГигаЧат: при первой загрузке файла показывается окно «Пользовательское соглашение сервиса ГигаЧат по работе с файлами» с галочкой и кнопкой «Продолжить». Раньше оно не закрывалось, превью не появлялось, и снимок считался неотправленным. Теперь галочка ставится и «Продолжить» нажимается автоматически.
- Превью вложения распознаётся и по карточке файла с именем screen.png/screen.jpg (DeepSeek показывает карточку, а не миниатюру).
- Если окно чата скрыто, оно на время прикрепления показывается прозрачным без фокуса: настоящие клики по скрытому окну не доходят.
- Счётчик «снимок не принят 3 раза» больше не отключает снимки до перезапуска: сбрасывается в начале каждой задачи.

## Чаты
- Агент работает в текущем (выбранном) чате. Раньше новый чат открывался почти на каждом шаге: при обрезке истории число сообщений уменьшалось, и это принималось за новую задачу.
- Новый чат открывается только по настройке «Открывать новый чат для каждой новой задачи», по «Новый чат после ходов» (по умолчанию 0 — никогда) или при очень длинном чате; не больше двух раз за задачу.

## Главный экран
- Настройка «Пауза каждые N шагов» (0 — без пауз), сохраняется.
- Кнопка «Взять управление» снова снимает паузу при повторном нажатии.

## Токены
- Счётчик токенов сохраняется между запусками (tokens.json в папке данных). Показ: эта сессия · прошлые сессии · всего; в подсказке — текущая задача.
