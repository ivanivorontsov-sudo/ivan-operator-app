Модель

Эта модель не видит изображения: она будет работать только по списку элементов интерфейса. Для управления по скриншотам выберите модель со зрением.

Точность

Встроенный браузер (веб-чат как «мозг») Расширения-VPN (например, PodsoVPN) внутри программы не работают: в Electron нет chrome.proxy. Укажите здесь адрес прокси (SOCKS5/HTTP) или запустите VPN-клиент для всей системы.
Вход выполняете вы сами в отдельном окне. Сессия хранится только на этом компьютере.

Поведение

Запасные провайдеры (сторож)

Если основная модель не отвечает, упирается в лимит или ошибку — агент переключится на следующую. Одна строка — один провайдер: провайдер | модель | ключ (необязательно), например groq | qwen/qwen3.8-27b | gsk_… или engine | local.

Этот файл (system_prompt.md) отправляется нейросети в каждом запросе. Ниже него программа сама добавляет раздел «Окружение»: ОС, разрешение, приложения, инструменты и список команд.







  
Встроенная модель — одна кнопка

  
Программа сама скачает движок llama.cpp и модель Qwen2.5-VL со зрением (без прав администратора и без отдельных программ), запустит её и включит в настройках. Сторож перезапустит движок, если он упадёт.

  
…

  
  

  
  
Или через Ollama

  
Нужна программа Ollama. Мастер сам скачает модель со зрением, создаст профиль ivan-operator (контекст, температура, системная инструкция) и включит его в настройках.

  
Проверяю Ollama…

  

  
  

  

  
Совет: на процессоре без видеокарты один шаг занимает 20–90 секунд. Для быстрой и точной работы — видеокарта NVIDIA от 8 ГБ или облачная модель (Claude, GPT-4.1, Gemini, Qwen2.5-VL-72B через OpenRouter).
Также можно указать запущенный llama-server (llama.cpp) в настройках: провайдер «llama.cpp server».





  
Android (adb / fastboot)

  
Официальные Google Platform-Tools скачиваются по кнопке. Включите на телефоне «Для разработчиков → Отладка по USB». На Windows нужен драйвер Google USB Driver; при ошибках fastboot на USB 3.0 используйте порт/хаб USB 2.0.

  

  

  
Прошивка (fastboot flash/erase/format, sideload, разблокировка загрузчика) и стирание данных выполняются только после вашего подтверждения в красном окне-предупреждении.





  
Удалённый доступ (телефон / другой ПК)

  
По умолчанию выключен. Включённый слушает только этот компьютер (127.0.0.1). Для телефона в той же Wi-Fi включите «Локальная сеть». Вход — по случайному токену, соединение шифруется (самоподписанный сертификат: браузер предупредит — сверьте отпечаток ниже).

  
  
  
  

  

  
Через интернет: (1) Tailscale — установите на ПК и телефон, включите «Локальная сеть» и откройте https://<tailscale-IP>:8787; (2) cloudflared: cloudflared tunnel --url https://127.0.0.1:8787 --no-tls-verify; (3) свой ретранслятор relay/relay.js (содержимое зашифровано ключом из токена, сервер его не видит).
