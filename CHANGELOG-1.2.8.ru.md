# ИванОператор 1.2.8
- Юридическое предупреждение и условия использования: окно при первом запуске (и при новой редакции текста) с прокруткой, флажком «Я прочитал(а) и принимаю», кнопками «Принять»/«Выйти».
- Принятие (редакция, дата, версия программы) хранится в settings.json; без него агент не запускается ни из окна, ни удалённо, ни по расписанию.
- «Настройки → Юридическая информация» — просмотр текста в любой момент. LEGAL.md в репозитории.
- Остальное без изменений (работа в том же чате, пауза каждые N шагов, «Автовыбор модели», поле задачи).
